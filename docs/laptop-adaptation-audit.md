# 笔记本主题适配排查

日期：2026-10-02。范围：48 套氛围主题、96 张浅深色角色图；简约主题无角色图。

## 发现与修复

- 本机物理分辨率 3200×2000，系统缩放 200%，逻辑屏幕约 1600×1000；当前用户浏览器实际内容高度未能直接读取，采用 1600×900 与 1600×1000 覆盖。
- 旧规则仅在宽度 ≤1439 或高度 ≤799 时回退，遗漏这类高分屏笔记本。改为宽度 ≤1680 或高度 ≤799；1920×1080 保持原有大屏规则。
- 旧 34vh 限制的是图片宽度，竖图高度仍会超标。现在从每张 WebP 读取宽高比，实际高度不超过窗口的 34%；≤900 宽时首页使用 26% 上限，会话角色层继续隐藏。
- 2026-10-03 修正：笔记本清晰模式保持角色前景显示、无角色蒙版，并在输入区背景中对齐重绘，避免被正文底色与输入区渐隐冲淡。柔和模式继续放在背景后方。两种模式共用等比限高，左下道具在紧凑窗口隐藏。此前退到正文后方的处理已撤回。
- 芙莉莲浅色在 1600×900 下原画布高约 840px，修复后约 306px，保持原始比例。

## 验证与限制

- 浏览器读取实际图片 naturalWidth/naturalHeight，与全部 96 个生成比例一致。
- 验证窗口：1366×768、1600×1000、1600×900、1920×1080、500×700、900×700；每个窗口遍历全部 96 张角色图，检查计算尺寸、层级及道具可见性。
- 查看全部 96 张图片的四张联系图及芙莉莲笔记本阅读样本。样本使用运行时原始装饰样式，正文为模拟布局；运行中 Harness 需要认证地址，未完成真实会话验收。
- 2026-10-03 补充：在 1600×900 独立浏览器样本对比芙莉莲浅色的清晰与柔和；清晰角色层 z-index 为 1、mask-image 为 none，输入区包含角色重绘；柔和角色层为 -1，无输入区角色重绘。对比截图为 outputs/frieren-laptop-clear-fixed.png 与 outputs/frieren-laptop-soft-fixed.png。此前 576 次检查中的清晰层级结论已由本条修正，尺寸结果仍有效。
- 15 项测试通过。构建输出重复生成一致，git diff --check 通过。
- npm run check 的生成检查以 HEAD 为基准，未提交的生成结果会触发差异退出；独立兼容检查另因本地 Harness 0.2.0-rc.2 与已验证基线 0.2.0-rc.1 不符而失败，未扩大兼容范围。
- 设计检测仅报告原有头像弹跳动画，与本次修改无关。
- 检查截图与原始结果在本机开发暂存目录 outputs/laptop-*，未放入仓库。

## 逐主题结果

2026-10-03 大屏回归：以修改前 HEAD 为基准，在浏览器中解析两版完整装饰样式，并通过独立视口匹配媒体查询。1681×800、1920×1080、2560×1440、3840×2160 下，生效的 40 条规则及顺序完全一致，包括清晰/柔和、首页、会话、横幅、角色与道具选择器。全部主题原有 token 值未变，仅新增小屏使用的图片比例 token。1600×900 按预期启用新的紧凑规则。本验证是浏览器样式回归，不代表运行中 Harness 的逐页截图验收。屏幕物理尺寸不参与判断：即使使用 27 寸显示器，若缩放或窗口宽度使内容视口 ≤1680px，或高度 ≤799px，仍会使用紧凑布局。原始结果：outputs/desktop-regression.json。
