# dsh-themes

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 提供角色插画与纯色主题。安装后，在**设置 → 主题与外观**中选择主题，并切换浅色、深色或跟随系统。

共 85 组主题，每组包含氛围版和简约版，共 340 套浅深色外观。氛围版包含角色壁纸、场景横幅和侧栏伙伴；简约版保留配色，不显示图片装饰。

## 安装

从 [GitHub Releases](https://github.com/EthanHannn/dsh-theme/releases) 下载 `dsh-themes-<版本>.tgz`。安装包无需解压，也无需构建。若尚无可用的 Release，可使用下方的源码目录安装方式。

在运行 Harness 的机器上执行以下命令，将路径替换为安装包的绝对路径：

```sh
dsh plugin --profile web add "/absolute/path/to/dsh-themes-0.2.0.tgz"
```

Windows 示例：

```powershell
dsh plugin --profile web add "C:/Users/YourName/Downloads/dsh-themes-0.2.0.tgz"
```

`web` 是目标配置名称。如果使用其他 profile，请替换为实际名称。从 Harness 源码运行时，在 Harness 仓库中使用 `pnpm dsh` 代替 `dsh`。

安装完成后，重启 Harness 服务并刷新网页。安装和启动应使用同一份 Harness CLI 和同一个 profile。

也可在 Harness 侧栏的**插件**页面输入安装包的绝对路径进行首次安装。该路径必须在 Harness 所在机器上可访问；更新已安装的主题包请使用命令行。

请保留下载的 `.tgz`，以便重装依赖或回退版本。GitHub 附带的 `Source code` 压缩包用于源码开发，安装时请选择 `.tgz` 附件。

### 从源码目录安装

克隆本仓库后，执行：

```sh
dsh plugin --profile web add /absolute/path/to/dsh-theme
```

此方式直接使用指定目录中的主题文件。安装后请保留目录及其位置。构建与本地开发方法见[开发指南](docs/DEVELOPMENT.md)。

## 选择主题

打开**设置 → 主题与外观**，按以下步骤选择：

1. 搜索主题名称，或通过动漫、游戏、其他分类筛选。关闭**显示简约**可隐藏纯色主题。
2. 点击主题预览效果，再选择浅色、深色或跟随系统。
3. 选择**清晰**或**柔和**调整壁纸效果。在**精细控制**中分别开关顶部横幅、右下角角色、左下角物件和侧栏角色。
4. 点击**应用**保存选择。

点击**返回当前主题**或离开设置页，会结束预览。**恢复默认**重置当前主题的装饰设置，保留明暗模式。选择**默认**并应用，可恢复 Harness 内置外观。

主题选择与装饰偏好保存在当前浏览器中，不跨设备同步。每套主题可分别保存明暗与装饰设置。

### 笔记本与小窗口

窗口宽度不超过 1680px 或高度不足 800px 时，主题自动缩小角色、隐藏左下角物件、收紧顶部横幅，并将首页输入框居中。宽度不超过 900px 时，隐藏顶部横幅和聊天页背景角色，首页仍保留角色插画。

## 更新与回退

下载新版 Release 的 `.tgz`，执行安装命令并替换为新文件路径，无需先卸载。更新后重启 Harness 服务并刷新网页。

回退时，下载旧版本安装包并执行相同命令。浏览器中的主题偏好会保留；若旧版本没有当前主题，请重新选择。请为不同版本保留不同的安装包文件名。

### 校验下载文件

将安装包的 SHA-256 与 Release 附件 `SHA256SUMS.txt` 中的值进行比较。Windows 可执行：

```powershell
Get-FileHash "C:/Users/YourName/Downloads/dsh-themes-0.2.0.tgz" -Algorithm SHA256
```

Linux 可在安装包所在目录执行 `sha256sum -c SHA256SUMS.txt`；macOS 可执行 `shasum -a 256 <安装包路径>`。

## 卸载

从目标 profile 中移除主题包：

```sh
dsh plugin --profile web remove dsh-themes
```

操作完成后，重启 Harness 服务并刷新网页。
